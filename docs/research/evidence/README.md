# أدلة تحليل ملف علم

`full_cell_extraction.json` يحفظ كل الخلايا والصيغ والقيم المخزنة وبصمة الملف الأصلي. `calculations.json` ونسخة CSV يعرضان 216 قيمة وحسابًا بمراجع المدخلات. `formula_reconciliation.json` يوثق 160 مطابقة للصيغ. `scenarios.csv` يحتوي 12 حساسية مشروطة ولا يمثل وفرًا متحققًا.

لإعادة الإنتاج باستخدام Python مع openpyxl:

```text
python3 extract.py "/path/to/Elm_Raw_Data_FY2023-FY2025 (2).xlsx"
python3 analyze.py
```

شغّل نسخة من هذا المجلد إذا أردت الحفاظ على ملفات الإثبات المسلمة؛ إعادة التشغيل تستبدل ملفات المخرجات هنا فقط. يحافظ الاستخراج على المصنف الأصلي دون تعديل. المحلل يدعم مجموعة العمليات التي ظهرت في هذا المصنف؛ ليس محرك Excel عامًا، ولا ضمانًا لحساب مصنفات أخرى. مطابقة القيم المحفوظة تثبت الاتساق الحسابي لهذه الصيغ ولا تثبت التعريف الاقتصادي للمؤشر أو صحة الاستنتاج التنفيذي.

تستخدم القيم المالية وحدة ألف ريال كما في الملف الأصلي ما لم يوضح حقل الوحدة خلاف ذلك. التقارير العربية تحول القيم إلى مليون ريال. راجع قيود تعريف صافي النقد والمرابحات والأرصدة الختامية في الحقول والتقرير قبل إعادة استخدام النسب.
