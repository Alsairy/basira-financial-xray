# بصيرة — Basira Financial X-ray

للتسليم إلى Claude: [ابدأ هنا](START_HERE.md)، [وصف الفكرة والتنفيذ بالإنجليزية](CLAUDE_HANDOFF.md)، و[نص جاهز لبدء العمل](CLAUDE_PROMPT.txt).

منتج محلي يعمل من رفع القوائم إلى المراجعة والتشخيص والتقرير حسب المتلقي، ثم متابعة التنفيذ والتحقق من الأثر. واجهة عربية باتجاه RTL مع الإنجليزية. بيانات محفوظة في SQLite ومستندات أصلية محلية، وصلاحيات تنفذ في الخادم.

## التشغيل

المتطلبات: Node.js 24 أو أحدث، Python 3.11 أو أحدث، وpnpm10.30.3. يستخدم المتصفح والخادم نفس الأصل.

```sh
pnpm install --frozen-lockfile --ignore-scripts
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock.txt
pnpm build
PYTHON_BIN=.venv/bin/python pnpm start
```

افتح **http://127.0.0.1:4317**. الخادم يرتبط افتراضيًا بعنوان الجهاز المحلي فقط. `data/` يحتوي البيانات والمرفقات ويجب حمايته؛ لا يضاف إلى Git. عند استعمال `NODE_ENV=production` تتطلب الجلسات HTTPS ويُعطّل وضع التجربة افتراضيًا. ذلك لا يكفي وحده لإقرار الجاهزية الإنتاجية.

للتطوير: شغّل الخادم كما سبق، وفي نافذة أخرى `pnpm dev` ثم افتح http://127.0.0.1:5178. منفذ Vite ثابت مع proxy إلى4317. لا يوجد نشر خارجي تلقائي.

في البيئة الحالية استُخدمت runtimes المرفقة بالتطبيق، ولا تحتاج هذه المسارات إلى اعتماد في بيئة أخرى. `scripts/start-local.mjs` يكتشف البيئة المرفقة إن لم تضبط `PYTHON_BIN`، ويتحقق من تبعيات Python قبل تشغيل الخادم. استخدم `node scripts/start-local.mjs` لإعادة التشغيل محليًا.

## التجربة الأولى

1. اختر «استكشف تجربة علم» لإنشاء مساحة تجربة معزولة. يُقرأ ملف `fixtures/elm.xlsx` عبر المحرك الحقيقي؛ لا تحقن أرقام في الواجهة.
2. اختر المتلقي: المجلس، CEO، CFO، المبيعات، المحلل، القطاع، أو العمليات. يؤثر المنظور في المؤشرات والأسئلة، ويتغير محتوى التقرير وأقسامه بحسب الجمهور والغرض والعمق.
3. لتجربة الاعتماد، اختر صلاحية المحلل في شريط التجربة. افتح البيانات، وافحص البنود والمصدر، وحدد البنود التي راجعتها ثم سجل المراجعة. تُحفظ كل مراجعة بإصدار وسبب.
4. بدّل إلى CFO لاعتماد البيانات، ثم أعد التحليل عند الحاجة. لا يستطيع معد البيانات اعتمادها منفردًا.
5. أنشئ مسودة التقرير بصلاحية المحلل، ثم اعتمدها بصلاحية CFO. نسخة المجلس تعرض التقارير المعتمدة فقط.
6. حوّل ملاحظة إلى إجراء بمسؤول وموعد وخط أساس. يرفع المنفذ الدليل ويطلب التحقق؛ يغلقه مراجع مستقل. اعتماد المبلغ المالي يتطلب خط أساس نقدي وفترة وطريقة قياس ومنع تداخل المبادرات.

تبديل الدور خاص بالتجربة؛ المستخدم الحقيقي لا يستطيع ترقية دوره. تنشئ مساحة خاصة باسم الشركة عند التسجيل، ويمكن لـCFO إضافة أعضاء محليًا من الإعدادات. لا تُرسل دعوات بالبريد.

## ما يعمل

- استيراد XLSX وCSV وPDF نصي، تحقق من النوع والحجم، مهام استخراج، بصمة ومنع تكرار المصدر.
- حفظ أصل القيمة والوحدة والإشارة والصيغة وموقعها. صيغ Excel المدعومة يعاد حسابها؛ التعارض أو الصيغة غير المحلولة يتطلب معالجة موثقة قبل الاعتماد.
- 35 تعريف مؤشر، لكل منها حالة أهلية، على الفترات المتاحة. ملف علم ينتج207حقائق و105نتائج مؤشرات. القيمة غير المتاحة تبقى null، ولا تتحول إلى صفر.
- 10 قواعد تشخيص مؤهلة حسب المدخلات؛ لا تعني المكتبة أن القواعد العشر تنطبق على كل شركة. علم يفعّل R01 وR04 وR06، مع فرضيات وحدود معلنة.
- مراجعة البنود، مصالحة المجاميع، سجل نسخ وفروق، إبطال الاعتماد بعد التعديل، وإصدارات تقارير ثابتة.
- سبعة قوالب متلقين، أربعة أغراض، وثلاثة أعماق. أرقام مشتركة ثابتة، أقسام وأولويات مختلفة، وروابط دليل داخل التقرير. القارئ لا يحصل على صلاحية إضافية بسبب اختيار الجمهور.
- خمسة مسارات سيناريو مع منخفض/أساسي/مرتفع؛ فصل تحرير النقد عن الربح والوفر التمويلي وتكلفة التنفيذ.
- نظراء مدخلون من المستخدم بمصدر وحق استخدام وتعريف. استبعاد فروق القطاع والفترة والعملة، وعينة صغيرة لا تنتج ترتيبًا. التجانس المحاسبي الدقيق يحتاج مراجعة بشرية.
- إجراءات، أدلة ومرفقات، تاريخ انتقالات، إقفال مستقل، قياس أثر وفترة وتداخل. تنبيهات تأخر داخل التطبيق للمالك وCFO، تمنع التكرار اليومي.
- توقع نقد لـ13أسبوعًا بمدخلات تشغيلية يراجعها المستخدم؛ لا يخمن التدفقات الأسبوعية من ثلاث قوائم سنوية.
- مساعد يسترجع الأدلة المتاحة وفق الدور، ويصرح بحدود الإجابة. لا توجد اتصالات نموذج خارجي مفعلة.
- سجل تدقيق، قياس فعلي لمدة المهام ونداءات المحرك، وتكاليف مراجعة يصرح بها المستخدم. تكلفة الحوسبة المحلية غير مسعرة.

## الاختبارات

```sh
pnpm check
pnpm test
.venv/bin/python -m unittest discover -s tests/engine -v
pnpm build
# بعد تشغيل الخادم؛ ينشئ مستخدمين وبيانات اختبار اصطناعية معزولة
pnpm test:e2e
pnpm exec playwright install chromium
pnpm test:browser
pnpm test:layout
```

اختبارات الخدمة تستخدم قواعد مؤقتة ومنافذ loopback عشوائية. اختبارAPI الشامل يعمل على الخادم المحدد بـ`BASE_URL`، ويضيف مساحات اصطناعية منفصلة. اختبارات الواجهة تستخدم `UI_URL` اختياريًا. لا تشغّل اختبارات إنشاء البيانات على بيئة إنتاج أو حسابات عملاء.

انظر [سجل التحقق](docs/VERIFICATION.md) و[تغطية المتطلبات](docs/IMPLEMENTATION_STATUS.md). مرور الفحوص المحددة لا يمثل شهادة أمان أو إمكانية تعميم دقة الاستخراج على كل قوالب الشركات.

## هيكل المشروع

- `src/`: واجهة React/TypeScript، الصفحات ومكونات الدليل والجمهور والنسخ والتكلفة.
- `server/`: Express، الجلسات والصلاحيات، قاعدة البيانات، العمل المالي والإجراءات والتقارير.
- `engine/`: استخراج وحسابات Decimal وقواعد وسيناريوهات Python.
- `shared/audiences.json`: قوالب المتلقين المشتركة ذات إصدار.
- `tests/`: اختبارات مالية وخدمية وAPI ومتصفح وقوالب التقارير.
- `fixtures/elm.xlsx`: النسخة التي قدمها المستخدم للمثال المحلي؛ يبقى ملف التنزيل الأصلي دون تعديل.
- `docs/`: العقد، منهج المتلقين، توثيق المحرك والخادم، التحقق، وحدود التشغيل.

## حدود الإطلاق

هذه نسخة تطوير محلية لاختبار المنتج مع فريق مالي. قبل خدمة عملاء فعلية يجب إنجاز مراجعة أمنية واستعادة نسخ احتياطية وإدارة هوية ومفاتيح وتشفير وتفويض شركات وصلاحيات مؤسسية، والتحقق المحاسبي على حزم متعددة مستقلة.

OCR للملفات المصورة، موصلات ERP والبنوك، مزود النظراء المرخص، PostgreSQL، SSO/MFA، إرسال البريد، تفويض مكتب استشاري منتهي الصلاحية، والتجميع المحاسبي للمجموعة غير مفعلة. تعدد الشركات متاح في مساحة العمل، دون جمع تلقائي لنسبها أو عملاتها. أرشفة المستند موجودة؛ الإزالة الشاملة ومشتقاتها والنسخ الاحتياطية تحتاج سياسة تنفيذ مستقلة. PDF المتاح الآن عبر طباعة HTML، وليس خدمة توليد PDF على الخادم.

الاعتماد المالي يبقى مستقلًا عن التشغيل الآلي. التحليل لا يثبت السببية أو تعثر الشركة. تحرير النقد سيناريو توقيت، وليس ربحًا. المبالغ المتحققة تحتاج دليلًا ومراجعًا مؤهلًا.

## الذكاء الاصطناعي الاختياري

المساعد المحلي يعمل دون إرسال ملفات إلى الخارج. تم إعداد عقد JSON والتحقق المحلي و20اختبارًا للاتصال المقترح، لكن **طبقة الاتصال الخارجي غير منفذة** بعد رفض مراجعة الموافقة الآلية لغياب تفويض محدد بالوجهة والحمولة. راجع [العقد المقترح](docs/AI_INTEGRATION.md) و[مثال الحمولة الاصطناعية](docs/AI_PAYLOAD_EXAMPLE.json). لا توجد مفاتيح مزود في المتصفح أو المستودع.

لم تُمنح بيانات المصنف أو العلامة التجارية رخصة نشر عامة في هذا التسليم. تراخيص الحزم المفتوحة تبقى لأصحابها؛ حدود المنتج لا تتجاوز حقوق مصادر العميل.
